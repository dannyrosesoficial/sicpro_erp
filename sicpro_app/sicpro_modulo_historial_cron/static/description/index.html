SICPRO ERP

Historial de Ejecución Cron

Descripción

Este módulo registra y gestiona el historial de ejecuciones de tareas programadas (cron) dentro del sistema SICPRO ERP.

Permite monitorear el comportamiento de los procesos automáticos, detectar fallos y enviar alertas a los roles configurados, garantizando mayor control y confiabilidad en la ejecución de tareas críticas del sistema.

Funcionalidades

  • ✔️ Registro detallado de ejecuciones de cron
  • ✔️ Monitoreo de tareas programadas
  • ✔️ Detección y registro de errores en procesos automáticos
  • ✔️ Envío de alertas a roles configurados
  • ✔️ Visualización cronológica del historial de ejecuciones

Notas

Este módulo es clave para la supervisión de procesos automatizados en SICPRO ERP, permitiendo anticipar incidencias y asegurar la correcta ejecución de tareas críticas mediante notificaciones oportunas a los responsables.
