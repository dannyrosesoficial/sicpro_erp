SICPRO ERP

Módulo Widget Color Picker

Descripción

Este módulo permite agregar un widget de selección de color en las vistas de SICPRO ERP, facilitando la elección visual de colores de forma rápida e intuitiva.

Está diseñado para mejorar la experiencia del usuario al trabajar con campos de color, permitiendo seleccionar valores cromáticos de manera gráfica sin necesidad de códigos manuales.

Funcionalidades

  • ✔️ Selector visual de colores en formularios
  • ✔️ Asignación de colores mediante widget
  • ✔️ Compatibilidad con campos de tipo char o color
  • ✔️ Mejora de la experiencia de configuración visual
  • ✔️ Integración directa con vistas de SICPRO ERP

Notas

Este módulo forma parte del ecosistema SICPRO ERP y puede integrarse con otros widgets para enriquecer la personalización visual de formularios y vistas.
