SICPRO ERP

Registros de Inicio de Sesión

Descripción

Este módulo permite registrar y visualizar la información de inicio de sesión de los usuarios dentro del sistema SICPRO ERP, almacenando datos relevantes para auditoría y control de accesos.

Está diseñado para proporcionar trazabilidad sobre la actividad de los usuarios, permitiendo identificar accesos al sistema, horarios de conexión y patrones de uso.

Funcionalidades

  • ✔️ Registro automático de inicio de sesión
  • ✔️ Captura de fecha y hora de acceso
  • ✔️ Identificación del usuario conectado
  • ✔️ Registro de IP o dispositivo de acceso
  • ✔️ Historial completo de autenticaciones

Notas

Este módulo es fundamental para auditoría de seguridad dentro del ecosistema SICPRO ERP, permitiendo rastrear la actividad de los usuarios en el sistema.

Se recomienda su uso en conjunto con políticas de seguridad y control de accesos.
