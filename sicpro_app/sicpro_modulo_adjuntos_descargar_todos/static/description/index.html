SICPRO ERP

Módulo de Descarga de Adjuntos en ZIP

Descripción

Este módulo permite descargar todos los archivos adjuntos asociados a registros dentro del sistema SICPRO ERP en un único archivo comprimido en formato ZIP, directamente desde la vista de lista.

Está diseñado para facilitar la gestión y exportación de documentos, optimizando el tiempo del usuario al evitar descargas individuales y permitiendo una manipulación más eficiente de múltiples archivos.

Funcionalidades

  • ✔️ Descarga masiva de archivos adjuntos en formato ZIP
  • ✔️ Acceso directo desde la vista de lista
  • ✔️ Compresión automática de múltiples archivos
  • ✔️ Compatibilidad con cualquier modelo del sistema
  • ✔️ Mejora en la eficiencia de gestión documental

Notas

Este módulo es especialmente útil en escenarios donde se requiere exportar grandes volúmenes de documentos. Forma parte del ecosistema SICPRO ERP y se integra de manera transparente con el sistema de adjuntos de Odoo.
