El Qr debe tener esta información para ser reconocido por la aplicación:

{
    "modelo": "nombre.del.modelo",
    "id": numeroID
}

Ejemplo:

{
    "modelo": "sicpro.app.contratos",
    "id": 4
}

Notas: Luego del ID no poner ,

El estilo debe ser como el JSON descrito anteriormente (entre llaves, sin coma al final del último elemento, con comillas modelo, valor del modelo y el id)
