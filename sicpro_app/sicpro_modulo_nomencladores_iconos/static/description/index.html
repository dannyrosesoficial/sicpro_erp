SICPRO ERP

Módulo de Nomenclador de Iconos

Descripción

Este módulo permite la visualización y gestión de los nomencladores de iconos dentro del sistema SICPRO ERP, facilitando la selección y uso de iconografía en los diferentes módulos.

Está diseñado para estandarizar el uso de iconos en la aplicación, mejorando la experiencia visual, la identificación de funcionalidades y la consistencia en la interfaz de usuario.

Funcionalidades

  • ✔️ Visualización centralizada de iconos disponibles
  • ✔️ Selección de iconos para uso en módulos y menús
  • ✔️ Estandarización de la iconografía del sistema
  • ✔️ Mejora de la experiencia de usuario (UX/UI)
  • ✔️ Integración con nomencladores y vistas del ERP

Notas

Este módulo complementa el sistema de nomencladores del SICPRO ERP, permitiendo una mejor organización visual y facilitando la configuración de interfaces más intuitivas y consistentes.
