SICPRO ERP

Paquetes Python

Descripción

Este módulo permite visualizar los paquetes de Python instalados en el servidor donde se ejecuta SICPRO ERP, proporcionando información detallada sobre las librerías disponibles en el entorno.

Está orientado a facilitar tareas de administración, diagnóstico y control del entorno técnico, permitiendo identificar versiones, dependencias y posibles conflictos en el sistema.

Funcionalidades

  • ✔️ Listado de paquetes Python instalados
  • ✔️ Visualización de versiones de cada librería
  • ✔️ Consulta de dependencias del entorno
  • ✔️ Apoyo en diagnóstico técnico del sistema
  • ✔️ Identificación de posibles conflictos de paquetes

Notas

Este módulo forma parte del ecosistema SICPRO ERP y está enfocado en administradores y desarrolladores, brindando visibilidad sobre el entorno Python del servidor para una mejor gestión y mantenimiento.
