SICPRO ERP

Módulo Widget Color Picker Bar

Descripción

Este módulo permite agregar un widget de selección de color en formato de barra de cuadros dentro de las vistas de SICPRO ERP, facilitando una selección visual rápida, clara y estructurada.

Está diseñado para mejorar la experiencia del usuario al elegir colores mediante una interfaz tipo paleta en bloques, evitando el uso de códigos manuales y optimizando la selección visual.

Funcionalidades

  • ✔️ Selector de color en formato de cuadros (color bar)
  • ✔️ Interfaz visual tipo paleta organizada
  • ✔️ Asignación rápida de colores en campos de formulario
  • ✔️ Integración con vistas de SICPRO ERP
  • ✔️ Mejora de la experiencia visual del usuario

Notas

Este módulo forma parte del ecosistema SICPRO ERP y puede combinarse con otros widgets de interfaz para mejorar la personalización visual de los formularios.
