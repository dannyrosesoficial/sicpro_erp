SICPRO ERP

Módulo de Gestión de Capacidad de Adjuntos

Descripción

Este módulo permite visualizar el tamaño de los archivos adjuntos almacenados en el sistema SICPRO ERP, facilitando el control y monitoreo del uso de almacenamiento asociado a documentos y registros.

Está diseñado para proporcionar mayor visibilidad sobre los recursos utilizados por los adjuntos, ayudando a identificar archivos de gran tamaño y optimizar la gestión del almacenamiento dentro del sistema.

Funcionalidades

  • ✔️ Visualización del tamaño de archivos adjuntos
  • ✔️ Monitoreo del uso de almacenamiento por registro
  • ✔️ Identificación de archivos de gran tamaño
  • ✔️ Apoyo en la gestión y optimización de recursos
  • ✔️ Integración con el sistema de adjuntos de SICPRO ERP

Notas

Este módulo complementa la gestión documental del SICPRO ERP, proporcionando herramientas útiles para el control del almacenamiento. Es especialmente recomendable en entornos con alto volumen de archivos adjuntos.
