SICPRO ERP

Simulación de Usuarios

Descripción

Este módulo permite simular sesiones de usuarios dentro del sistema SICPRO ERP, facilitando la validación de permisos, accesos y comportamiento del sistema sin necesidad de iniciar sesión directamente con cada usuario.

Está diseñado para entornos de desarrollo, pruebas y soporte técnico, permitiendo replicar escenarios reales de uso y detectar incidencias relacionadas con roles y seguridad.

Funcionalidades

  • ✔️ Simulación de inicio de sesión de usuarios
  • ✔️ Validación de permisos y grupos de acceso
  • ✔️ Pruebas de roles sin afectar la sesión real
  • ✔️ Cambio temporal de usuario para soporte técnico
  • ✔️ Entorno seguro para pruebas funcionales

Notas

Este módulo forma parte del ecosistema SICPRO ERP y está orientado exclusivamente a pruebas, desarrollo y soporte. No debe utilizarse en producción sin los controles adecuados de seguridad y auditoría.
