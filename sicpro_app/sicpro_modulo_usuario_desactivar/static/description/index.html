SICPRO ERP

Desactivación de Usuarios

Descripción

Este módulo permite la desactivación controlada de usuarios dentro del sistema SICPRO ERP, aplicando reglas de seguridad basadas en control de accesos y políticas de directorio LDAP empresarial.

Está diseñado para garantizar la administración segura del ciclo de vida de los usuarios, permitiendo deshabilitar accesos de forma centralizada y auditada.

Funcionalidades

  • ✔️ Desactivación de usuarios del sistema
  • ✔️ Integración con LDAP empresarial
  • ✔️ Control de accesos basado en reglas de seguridad
  • ✔️ Registro de auditoría de desactivaciones
  • ✔️ Gestión centralizada de usuarios inactivos

Notas

Este módulo es esencial para mantener la seguridad del ecosistema SICPRO ERP, especialmente en entornos corporativos con gestión de identidades centralizada.

Se recomienda revisar periódicamente los usuarios desactivados para garantizar una correcta administración de accesos.
