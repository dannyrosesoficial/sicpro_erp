Odoo Gantt View

This module only adds a gantt view in backend side, you need to buy the module "Dom Gantt View" in order to see gantt in user interface.

View More

Integration

You can create new gantt view for all models.

Scale Definition

There are 4 available scales: Day, Week, Month, and Year. You could define which will be shown on the view.

Columns Adding

You can add more columns to the gantt view, same as adding to the tree (list) view
