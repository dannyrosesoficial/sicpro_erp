SICPRO ERP

Timeout de Sesión

Descripción

Este módulo permite gestionar el tiempo de expiración de las sesiones de usuario dentro del sistema SICPRO ERP, cerrando automáticamente la sesión cuando se alcanza el tiempo de inactividad definido.

Está diseñado para mejorar la seguridad del sistema, evitando accesos no autorizados cuando los usuarios dejan sesiones abiertas sin supervisión.

Funcionalidades

  • ✔️ Cierre automático de sesiones por inactividad
  • ✔️ Configuración del tiempo máximo de sesión
  • ✔️ Mejora de la seguridad del sistema
  • ✔️ Protección contra accesos no autorizados
  • ✔️ Integración con la gestión de usuarios del sistema

Notas

Este módulo forma parte del ecosistema SICPRO ERP y es fundamental para garantizar la seguridad operativa, especialmente en entornos con múltiples usuarios o accesos compartidos.

Se recomienda configurar tiempos de expiración adecuados según las políticas de seguridad de la organización.
