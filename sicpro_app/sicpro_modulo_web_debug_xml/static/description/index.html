SICPRO ERP

Web Debug XML

Descripción

Este módulo permite activar herramientas de depuración avanzadas para la inspección de archivos XML dentro del modo desarrollador de SICPRO ERP.

Está diseñado para facilitar a los desarrolladores la visualización, análisis y trazabilidad de las vistas XML, herencias y estructuras técnicas utilizadas en el sistema.

Funcionalidades

  • ✔️ Inspección de vistas XML en modo debug
  • ✔️ Visualización de estructuras de herencia
  • ✔️ Análisis de vistas heredadas y originales
  • ✔️ Depuración de errores en XML
  • ✔️ Soporte para desarrolladores en tiempo real

Notas

Este módulo está orientado exclusivamente a entornos de desarrollo. Su uso permite comprender la composición interna de las vistas XML en SICPRO ERP, facilitando la depuración y mantenimiento del sistema.
