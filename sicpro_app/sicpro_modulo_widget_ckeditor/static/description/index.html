SICPRO ERP

Módulo Widget CKEditor

Descripción

Este módulo permite la creación y edición de contenido enriquecido en campos de tipo texto o HTML dentro de SICPRO ERP, utilizando el moderno editor WYSIWYG CKEditor.

Está diseñado para facilitar la edición de contenido visual, permitiendo a los usuarios dar formato, insertar elementos y mejorar la presentación de la información sin necesidad de conocimientos técnicos.

Funcionalidades

  • ✔️ Editor visual WYSIWYG integrado en SICPRO ERP
  • ✔️ Edición avanzada de campos text/html
  • ✔️ Formateo de texto (negrita, listas, estilos)
  • ✔️ Inserción de enlaces, imágenes y contenido multimedia
  • ✔️ Experiencia de edición moderna y fluida

Notas

Este módulo forma parte del ecosistema SICPRO ERP y puede integrarse con otros módulos para mejorar la gestión de contenido y la presentación de información en el sistema.
