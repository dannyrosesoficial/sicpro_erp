SICPRO ERP

Configuración de URL del Sistema

Descripción

Este módulo permite modificar y gestionar la URL base de acceso de SICPRO ERP, adaptándolo a distintos entornos como desarrollo, pruebas o producción.

Está diseñado para facilitar la configuración del sistema sin necesidad de intervención directa en el servidor o archivos de configuración, permitiendo una administración más flexible del entorno.

Funcionalidades

  • ✔️ Configuración de URL base del sistema
  • ✔️ Adaptación a entornos de desarrollo, staging y producción
  • ✔️ Cambio dinámico sin necesidad de reinicio complejo
  • ✔️ Centralización de la configuración de acceso
  • ✔️ Mejora en la gestión de despliegues del sistema

Notas

Este módulo es crítico para la correcta configuración del entorno de SICPRO ERP, especialmente en escenarios donde el sistema se despliega en múltiples servidores o dominios.

Se recomienda validar cuidadosamente la URL configurada para evitar problemas de acceso o redirección.
