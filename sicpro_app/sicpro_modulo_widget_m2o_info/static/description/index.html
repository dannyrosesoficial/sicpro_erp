SICPRO ERP

Widget Many2One Info

Descripción

Este widget permite visualizar información adicional asociada a un campo Many2One dentro de SICPRO ERP, mostrando resultados de búsqueda de forma clara y estructurada.

Facilita la selección de registros relacionados al mostrar una lista enriquecida con datos relevantes, mejorando la experiencia de búsqueda y selección del usuario.

Funcionalidades

  • ✔️ Visualización de información extendida en Many2One
  • ✔️ Lista de búsqueda enriquecida con datos relevantes
  • ✔️ Mejora en la selección de registros relacionados
  • ✔️ Integración con modelos de SICPRO ERP
  • ✔️ Interfaz optimizada para búsqueda rápida

Notas

Este módulo forma parte del ecosistema SICPRO ERP y está orientado a mejorar la experiencia de usuario en campos relacionales Many2One dentro de formularios y vistas.
